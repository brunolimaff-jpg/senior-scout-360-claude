# Contrato com o plugin Documentacao Senior

## Limite verificado do plugin parceiro
Plugin Documentacao Senior, versao observada 1.3.1 (plugin ID no workspace ChatGPT/Codex: Plugin_78ddd1bfab048191851d98a1d0b10803). Ele tem skills para pesquisar documentacao, comparar produtos, novidades, auditar promessas e traducao comercial. Nao tem MCP remoto obrigatorio. Seu acervo SQLite historico nao e executado automaticamente em hosts web.

A disponibilidade depende do host: no Claude, ele so existe se estiver instalado e habilitado na sessao (aparece como skills `documentacao-senior:*` ou equivalente). Nao presumir que esta instalado; verificar a lista de skills disponiveis.

## Quando usar
Somente apos existir problema, processo ou hipotese comercial relevante e for preciso confirmar o que um produto Senior documentadamente faz. Se a pessoa perguntar diretamente pelo produto, pode começar pela documentacao.

## Como usar
1. Formular pergunta verificavel: processo, funcionalidade, linha, modulo, versao e condicoes.
2. Quando o plugin parceiro estiver efetivamente selecionado e disponivel no ambiente, usar suas habilidades apropriadas; um plugin nao ganha poder de invocar outro automaticamente so por referencia textual.
3. Caso o host nao exponha esse plugin no mesmo fluxo, usar pesquisa documental oficial realmente disponivel ou orientar selecionar o plugin parceiro e compartilhar o contexto minimo necessario. Nunca alegar que o invocou sem isso ter acontecido.
4. Acesso a documento oficial e leitura da pagina especifica sustentam uma funcao documentada; texto historico, sitemap, marketing ou titulo do link so descobrem candidatos.
5. Separar ERP XT, ERP senior X, ERP Mega, Senior X Platform, GAtec, SimpleFarm, HCM, WMS, TMS e demais linhas; nao inferir equivalencia entre marcas nem migrar recursos de uma versao para outra.
6. Nao afirmar contratacao, uso, disponibilidade no prospect, precificacao, integracao, licenciamento ou capacidade ativa somente pela documentacao.
7. Saida: processo observado -> fato documental confirmado (fonte, modulo, versao, condicao) -> valor possivel (inferencia) -> pergunta discriminante -> proximo passo.
8. Se a documentacao nao estiver acessivel ou a versao nao estiver clara, status NAO COMPROVADO; sem promessa de funcionalidade.

## Dependencia
O Scout 360 tem valor autonomo para conta, reunioes e oportunidades. A Documentacao Senior e uma referencia complementar por demanda, nao dependencia que interrompe a pesquisa da empresa.
