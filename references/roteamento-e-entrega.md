# Roteamento do Senior Scout 360

O Scout principal trabalha por necessidade, nao dispara todos os modulos.

| Intencao | Especialista principal |
| --- | --- |
| Preparar conta ou prospect de ponta a ponta | inteligencia-de-conta |
| CNPJ, socios, grupo, matriz, filiais | investigar-grupo-economico |
| Processos, cadeia de valor, riscos operacionais | analisar-operacao-e-processos |
| Sistemas, ERP, concorrentes, integracoes existentes | investigar-tecnologias-e-concorrencia |
| Pessoas, influenciadores, aprovacao, sponsor | mapear-pessoas-e-decisao |
| Conferir fontes, alegacoes, contradicoes | auditar-evidencias-comerciais |
| Conectar problema a capacidade da Senior | avaliar-aderencia-portfolio-senior |
| Dossie completo a partir de frentes e fontes | consolidar-dossie-executivo |
| Uma reuniao / transcricao / ata | analisar-reuniao |
| Historico de oportunidade / CRM | revisar-oportunidade |
| Forecast ou fechamento periodico | fechamento-de-trimestre |
| Apenas proxima acao | proximo-movimento-comercial |

## Ordem por necessidade
Alvo -> identidade -> fatos do processo da empresa -> lacuna comercial -> consulta documentacao Senior somente se for preciso sustentar capacidade -> sintese -> proxima validacao.

## Escopo setorial
Priorizar setor real da empresa. Agro e uma especializacao opcional do Scout e nunca e o padrao presumido. Usar vocabulos, indicadores e processos por setor somente quando fizerem sentido. Nao deduzir produto Senior de CNAE, area plantada ou segmento.

## Profundidade
Consulta rapida: 1 a 3 evidencias criticas e 1 proximo passo. Investigacao especifica: aprofundar uma frente. Dossie: sintetizar as frentes sustentadas sem repeticoes. Falta de informacao nao obriga criar secao ficticia.

## Tecnologia e integracoes
Este pacote adiciona habilidades textuais, nao MCP, API, RAG, banco de dados, busca automatica ou escrita no CRM. Nao declarar execucao de recurso que nao foi conectado e testado.
